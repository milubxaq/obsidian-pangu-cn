# 中文排版助手（Obsidian）

自动整理中文排版：中英文之间、中文与数字之间补空格，清掉中文标点前后的多余空格。

## 功能

- **格式化当前笔记**：命令面板搜索「中文排版」
- **格式化选中内容**
- **格式化当前文件夹内所有笔记**（批量，谨慎使用，建议先备份）
- **粘贴时自动排版**：从网页复制内容粘贴进笔记自动整理
- **编辑器右键菜单**快捷入口

自动跳过代码块、行内代码、URL、Markdown 链接地址、Wiki 链接与 HTML 标签。

## 设置

设置 → 第三方插件 → 中文排版助手：

| 选项 | 默认 | 说明 |
| --- | --- | --- |
| 中英文之间补空格 | 开 | 核心功能 |
| 半角标点转全角 | 关 | 较激进，按需开启 |
| 粘贴时自动排版 | 开 | 从网页剪藏时很实用 |

## 安装

社区插件市场审核通过后可直接搜索安装。在此之前可手动安装：把 `main.js`、`manifest.json` 放入
`<vault>/.obsidian/plugins/pangu-cn/`，重启 Obsidian 后在第三方插件中启用。
